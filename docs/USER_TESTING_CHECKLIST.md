# User Testing Checklist

## Pre-Testing Preparation
- [ ] Devices charged and ready
- [ ] Internet connection available
- [ ] Test environment setup
- [ ] Feedback forms printed/prepared
- [ ] Testing instructions prepared
- [ ] Consent obtained from participants

## During Testing
- [ ] Record completion times
- [ ] Note any error messages
- [ ] Observe user frustration points
- [ ] Document suggestions
- [ ] Ask about cultural relevance
- [ ] Check language comprehension

## Post-Testing
- [ ] Collect all feedback forms
- [ ] Compile data
- [ ] Identify top 5 issues
- [ ] Plan improvements
- [ ] Share results with team
- [ ] Update backlog with user stories
