# AquaLearn User Testing Guide

## Testing Overview
This guide provides instructions for conducting user testing with fish farmers in Nigeria.

## Testing Objectives
1. Validate usability and accessibility
2. Assess content clarity and relevance
3. Identify technical issues on various devices
4. Gather feedback for improvements

## Testing Environment
- **Devices**: Smartphones (Android/iOS), Tablets, Basic feature phones
- **Internet**: 3G, 4G, slow Wi-Fi, offline scenarios
- **Browsers**: Chrome, Firefox, Safari

## Test Scenarios

### Scenario 1: Account Creation
**Instructions:**
1. Visit the AquaLearn website
2. Click "Sign Up"
3. Fill in the registration form
4. Complete the onboarding process

**Checklist:**
- [ ] Can user find the sign-up button?
- [ ] Are form fields clear and easy to understand?
- [ ] Is error messaging clear?
- [ ] Can user complete onboarding without confusion?

### Scenario 2: Course Discovery
**Instructions:**
1. Browse available courses
2. Use filters to find specific courses
3. Search for a course
4. View course details

**Checklist:**
- [ ] Can user find courses easily?
- [ ] Are filters intuitive?
- [ ] Is search functionality working?
- [ ] Is course information clear and complete?

### Scenario 3: Learning Experience
**Instructions:**
1. Enroll in a course
2. Watch a video lesson
3. Take the quiz
4. Track progress

**Checklist:**
- [ ] Does video load properly?
- [ ] Can user control playback?
- [ ] Is quiz interface intuitive?
- [ ] Is feedback clear?
- [ ] Can user track progress easily?

### Scenario 4: Certificate
**Instructions:**
1. Complete all lessons in a course
2. View certificate
3. Download certificate
4. Share certificate

**Checklist:**
- [ ] Is certificate displayed properly?
- [ ] Can user download PDF?
- [ ] Is certificate information correct?
- [ ] Can user share certificate?

### Scenario 5: Profile Management
**Instructions:**
1. View profile page
2. Update profile information
3. Upload profile picture

**Checklist:**
- [ ] Can user find profile page?
- [ ] Is form easy to use?
- [ ] Does image upload work?
- [ ] Are changes saved properly?

## Testing Instructions for Facilitators

1. **Set up environment**: Ensure devices are ready with internet connection
2. **Explain purpose**: Briefly explain the testing purpose
3. **Observe**: Watch how users interact without interfering
4. **Take notes**: Document issues and user reactions
5. **Ask follow-up**: Ask clarifying questions after tasks
6. **Thank participants**: Show appreciation for their time

## Post-Testing Actions

- Compile all feedback forms
- Identify common issues
- Prioritize improvements
- Update user stories
- Implement fixes

## Success Criteria

- 80% of users can complete registration
- 70% can successfully watch a video lesson
- 60% can pass a quiz
- Users rate experience 4+ out of 5
- Minimal technical issues reported
